# 生涯导航平台产品化界面重构设计

## 决策与范围

用户已授权由开发者自主选择方案。采用 **Balanced System**：以 Apple 的阅读舒适度、克制留白和清晰动作层级为主；仅在准备度、能力差距、成长趋势等需要比较的数据中使用 NVIDIA 式黑底、网格和高对比绿色信号。

本轮重构不改变“本地演示原型、规则推荐、可选 DeepSeek 辅导”的数据边界，也不把模拟数据伪装成学院真实统计。所有既有角色和可用功能继续保留：低年级探索、高年级诊断与路线、研究生双线规划、教师匿名样本看板。

## 核心体验

### 学生主线

学生首次进入只需完成一套短画像，随后落到“工作台”。工作台把唯一的下一件事放在屏幕首位，明确该行动的时长、产出和它会改变什么；进度、准备度和方向信息退到第二层。学生可以从此处进入探索、诊断或任务清单，在每个任务上完成、补充证据和记录反思。

低年级的体验语言是“试一试、留下证据、再决定”；高年级是“选择目标、看清差距、按周补齐”。页面不使用泛泛的“职业测评”结论，不显示无法解释的总分。

### 信息结构

```text
首页 → 两步入门 → 学生工作台
                       ├─ 探索方向（低年级）
                       ├─ 目标诊断（高年级）
                       └─ 本周计划 / 反思
研究生入口 → 研究证据 → 科研线 + 职业线
教师入口   → 脱敏模拟样本 → 资源需求与教学建议
```

主导航始终只显示当前身份必要的 3–4 项入口。页面顶部保留阶段、路径、存储状态和重置入口，不把所有角色入口混在一起。

## 视觉系统

- 页面底色为暖白 `#F6F7F4`，正文为近黑 `#101411`，不再使用大面积玻璃拟态和渐变。
- 品牌绿为 `#76B900`，只承担完成、可行动、增长和关键数据状态；不作为大面积装饰色。
- 深色“Signal Panel”只用于能力雷达、匹配分、趋势和研究成果证据，使用细网格和固定宽度数字字体。
- 卡片改为薄边框、12–18px 圆角、低阴影；使用明确标题、说明、状态和主按钮，不使用无意义的小标签堆砌。
- 字体优先使用系统中文字体；数值和阶段标签使用 `ui-monospace`。在 768px 以下单列布局，固定底部主操作只在移动端显示。

## 功能完成度要求

1. **完整任务闭环**：工作台、探索、诊断、路线图和研究生双线任务都显示状态；任务可完成、添加简短反思并持久化。
2. **可解释诊断**：岗位结果明确显示规则来源、前三项短板、建议证据和生成计划入口；路径切换会重新生成而非隐藏旧结果。
3. **可用空状态**：未完成入门、没有任务、没有研究成果、未配置 AI 时，均给出明确下一步而不是空卡片。
4. **AI 是可选补充**：只在学生明确点击后发送被列出的最小画像字段；不可用时规则流不受影响。
5. **角色完整一致**：研究生与教师使用同一视觉骨架，分别突出双线里程碑和匿名聚合洞察。

## 组件边界

| 单元 | 职责 | 不负责 |
| --- | --- | --- |
| `PageShell` | 身份导航、阶段状态、页面布局和隐私提示 | 业务计算 |
| `ActionFocusCard` | 解释当前唯一下一步、时长、产出和完成反馈 | 生成路线 |
| `ProgressRail` | 可视化阶段与任务完成度 | 修改任务 |
| `EvidencePanel` | 呈现能力/成果的可解释信号 | 推断真实学院数据 |
| 页面模块 | 组织角色任务和调用规则服务 | 存储实现 |
| `careerStore` | 本地状态、迁移、任务与反思持久化 | API 请求 |

## 错误处理、边界和验收

- 所有表单拥有可见标签、错误文本和键盘焦点；未选择必要项时阻止下一步并解释原因。
- `localStorage` 失败或版本不兼容时显示可恢复提示；重置只重置本地演示数据。
- 控制台无错误；关键交互在 390px 宽度没有水平滚动；刷新深链接不丢失任务状态。
- 继续使用模拟/脱敏数据；AI 服务密钥仅在服务端运行环境中存在。
